何ができる？

イーグレットツーミニのUSBコントローラをWindows PCに直接接続し、無料のソフトウェアで入力を変換します。ゲーム機本体やRP2040は不要です。

01 · 回転操作

パドルはWindowsでマウスホイールとして認識されます。AutoHotkeyで左右方向のマウス移動に変換し、MesenのVAUSを動かします。

02 · 発射ボタン

通常のマウスクリックとしては認識されないため、USBPcapとTSharkを使ってボタンのHID入力を検出し、MesenにSpaceキーを送ります。

必要なもの

ハードウェア

Windows 10/11 PCと「イーグレットツーミニ パドル＆トラックボールコントローラ」。検証したUSB識別子は VID 0AE4 / PID 0701 です。

無料ソフト

MesenCE または Mesen 2（検証はMesen 2系）

AutoHotkey v2、Wireshark（TSharkを含む）、USBPcap

USBPcapの導入後はWindowsを再起動してください。Mesenのメニュー名は使用バージョンで異なる場合があります。

設定手順

1

MesenでVAUSを有効にする

Mesenの Settings → NES → Input を開き、日本版なら拡張端子の Arkanoid Controller (Famicom) を選択します。海外NES版はポート2の Arkanoid Controller (NES) を選択。専用コントローラの Fire を Space に設定します。普通のUSBマウスを左右に動かしてVAUSの反応を試すと便利です。

2

AutoHotkeyを起動する

mesen_spinner.ahk をダブルクリックします。パドルの回転でマウスが左右に動き、MesenでもVAUSが動くことを確認します。左右逆ならファイルの -10 と 10 を入れ替えます。速度も数値の変更で調整できます。

#Requires AutoHotkey v2.0
#SingleInstance Force
A_MaxHotkeysPerInterval := 500
WheelUp::MouseMove(-10, 0, 0, "R")
WheelDown::MouseMove(10, 0, 0, "R")
^!q::ExitApp()

Ctrl + Alt + Q で終了できます。

3

いったんUSBを抜く

Wiresharkのキャプチャが動いていたら停止し、イーグレットツーミニのコントローラをUSBから抜きます。

4

発射ボタン監視を開始

START_FIRE.cmd をダブルクリックし、黒い画面でEnterを押します。Starting USBPcap1 monitoring の表示後にUSBを差し直します。TAITO detected と表示されたら認識成功です。

5

Mesenでプレイ

Mesenを前面にして『アルカノイド』を起動。パドル回転でVAUS移動、本体ボタンでボール発射。黒い画面に Fire! が表示されればボタン入力の検出に成功しています。

終了するときは、AHK側が Ctrl + Alt + Q、発射側が黒い画面を前面にして Ctrl + C です。

よくある問題

パドルが反応しない

MesenのArkanoid Controller設定、AutoHotkey v2の実行状態、普通のUSBマウスでのVAUS動作を確認してください。

「71 hotkeys have been received...」と出る

イーグレットツーミニは短時間に大量のホイール入力を送ります。配布版の A_MaxHotkeysPerInterval := 500 で警告の閾値を上げています。

「Capture failed: Capturing on 'USBPcap1'」と出る

以前の試作版では、TSharkの正常なステータス出力をPowerShellがエラー扱いしていました。ここにある修正版を使ってください。

TAITO detected が表示されない

USBを抜く → CMDを起動 → Enter → USBを挿す、の順番を確認します。USBPcapのインターフェースが1以外の場合、mesen_fire.ps1 の -i USBPcap1 を正しい番号へ変更してください。

Fire! と表示されても発射しない

MesenでFireにSpaceキーを割り当てたか、Mesenが前面のウィンドウかを確認してください。

検証したUSB入力

状態HID Data（5バイト）
押す前00 00 00 00 00
押下中00 01 00 00 00
離した後00 00 00 00 00

2バイト目の最下位ビットを検知して、Mesenが前面のときだけスペースキーを送ります。詳しくは 技術メモ をご覧ください。

これは1台の個体とWindows環境での動作報告です。MesenCEのすべてのバージョンや長時間の安定性は未確認です。また、USBPcapは対象機器以外のUSB通信を含む場合があるため、記録ファイルを安易に公開しないでください。
