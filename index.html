何ができる？

イーグレットツーミニのUSBコントローラをWindows PCに直接接続し、無料のソフトウェアで入力を変換します。ゲーム機本体やRP2040は不要です。

01 · 回転操作

パドルはWindowsでマウスホイールとして認識されます。AutoHotkeyで左右方向のマウス移動に変換し、MesenのVAUSを動かします。

02 · 5ボタンのキー割り当て

USBPcapとTSharkでボタン入力を検出し、操作中のアプリに設定したキーを送ります。Mesen以外でも使用できます。左右を発射、上部下をスタートにしたり、上部左右をZ・Xに割り当てたりできます。

必要なもの

ハードウェア

Windows 10/11 PCと「イーグレットツーミニ パドル＆トラックボールコントローラ」。検証したUSB識別子は VID 0AE4 / PID 0701 です。

無料ソフト

MesenCE または Mesen 2（検証はMesen 2系）

AutoHotkey v2、Wireshark（TSharkを含む）、USBPcap

USBPcapの導入後はWindowsを再起動してください。Mesenのメニュー名は使用バージョンで異なる場合があります。

ダウンロードするスクリプト

最新版をまとめてダウンロード（ZIP）

ZIPを展開し、scripts フォルダのファイルを使います。全アプリ対応・MAME用スキャンコード修正版を収録しています。更新する場合は、編集済みの buttons.json を残してください。

次の5ファイルを同じフォルダに保存してください。ボタンの割り当ては buttons.json で変更できます。

5つのボタンを割り当てる

buttons.json をメモ帳などで編集し、保存してからボタン変換を再起動します。左右はSpace、上部下はEnter、上部左右は未割り当てが初期設定です。

物理ボタン設定名初期キー
右rightSpace
左leftSpace
上部左topLeft未割り当て
上部右topRight未割り当て
上部下topBottomEnter

初期設定

{
  "right": "Space",
  "left": "Space",
  "topLeft": null,
  "topRight": null,
  "topBottom": "Enter"
}

アルファベットキーを使う例

A〜Zにも対応しています。上部左をZ、上部右をXにする設定は次のとおりです。大文字・小文字はどちらでも使えます。

{
  "right": "Space",
  "left": "Space",
  "topLeft": "Z",
  "topRight": "X",
  "topBottom": "Enter"
}

保存したらボタン変換を終了し、START_FIRE.cmd を再起動してください。MesenやMAMEなど、使用するアプリ側でもZとXに使いたい機能を割り当てます。無効にするには引用符なしの null を指定し、5つの設定名は省略せず残してください。

使用可能：A〜Z、0〜9、F1〜F12、Space、Enter、Escape、Tab、Backspace、Left、Right、Up、Down、Home、End、PageUp、PageDown、Insert、Delete。Esc と Return も使えます。Ctrl+Z のような複合キーには対応していません。

詳しい設定方法（README）

左右に同じSpaceを割り当てた場合、両方を離すまでSpaceを保持します。この版は全アプリで有効です。通常のキーボードと同じように操作中（前面）のアプリへキーを送ります。アプリを切り替えても、ボタンを離すまで押下状態を保持します。終了は黒い画面でCtrl+Cです。

USBを抜き差しするときは変換を終了してから起動手順をやり直してください。

Mesenでの設定手順

1

MesenでVAUSを有効にする

Mesenの Settings → NES → Input を開き、日本版なら拡張端子の Arkanoid Controller (Famicom) を選択します。海外NES版はポート2の Arkanoid Controller (NES) を選択。専用コントローラの Fire を Space に、通常の1Pコントローラの Start を Enter に設定します。普通のUSBマウスを左右に動かしてVAUSの反応を試すと便利です。

2

AutoHotkeyを起動する

mesen_spinner.ahk をダブルクリックします。パドルの回転でマウスが左右に動き、MesenでもVAUSが動くことを確認します。左右逆ならファイルの -10 と 10 を入れ替えます。速度も数値の変更で調整できます。

#Requires AutoHotkey v2.0
#SingleInstance Force
A_MaxHotkeysPerInterval := 500
WheelUp::MouseMove(-10, 0, 0, "R")
WheelDown::MouseMove(10, 0, 0, "R")
^!q::ExitApp()

Ctrl + Alt + Q で終了できます。

3

いったんUSBを抜く

Wiresharkのキャプチャが動いていたら停止し、イーグレットツーミニのコントローラをUSBから抜きます。

4

発射ボタン監視を開始

START_FIRE.cmd をダブルクリックし、黒い画面でEnterを押します。Starting USBPcap1 monitoring の表示後にUSBを差し直します。TAITO detected と表示されたら認識成功です。

5

Mesenでプレイ

Mesenを前面にして『アルカノイド』を起動。パドル回転でVAUS移動、右または左ボタンで発射、上部下ボタンでスタート。黒い画面に Key down: 0x20、離すと Key up: 0x20 が表示されます。Enterは 0x0D です。

終了するときは、AHK側が Ctrl + Alt + Q、発射側が黒い画面を前面にして Ctrl + C です。

MAMEUI64でアルカノイドを遊ぶ

確認環境：MAMEUI64 0.263.0（Feb 28 2024）／Windows。 2026年11月22日、ユーザー環境でパドル回転と本体右ボタンによる発射を確認しました。使用したゲーム設定は arkanoidjb です。

1

MAMEの入力方式を変更

MAMEUIを終了してから、ini/mame.ini など実際に読み込まれる設定ファイルの次の項目を書き換えます。

keyboardprovider          win32
mouseprovider             win32
mouse                     1

arkanoidjb.ini などのゲーム専用INIにも同じ項目がある場合は、そちらが優先されるため同じ値にします。今回の環境では実行ファイルと同じフォルダと ini フォルダの両方にゲーム用INIがありました。別のROMセットでは、そのセットの設定も確認してください。

標準のRawInputでは、今回のソフトウェアによるキー・マウス入力を受け取れない場合があります。win32 は0.263でも使えます。0.263の公式資料

2

回転とボタンの変換を両方起動

mesen_spinner.ahk を起動します。次にUSBを抜き、START_FIRE.cmd を起動してEnterを押し、監視開始後にUSBを挿します。TAITO detected が出たらMAMEUIでゲームを開いてください。

START_FIRE.cmd だけでは回転は変換されません。全アプリ版の表示は Input target: ALL APPLICATIONS です。

3

ゲーム内でキーと軸を割り当てる

ゲーム中にTabを押して、そのゲームの入力設定を開きます。項目名はバージョン・表示言語によって異なります。

MAME側の入力割り当て
P1 Dial AnalogマウスX軸
P1 Button 1（発射）Space
1 Player StartEnter
Coin 1通常はキーボードの5

マウスX軸は、割り当て待ちの状態で普通のマウスを左右に動かして設定できます。ダイヤルの増加・減少欄ではなく、アナログ入力本体に割り当てます。先に普通のキーボードとマウスで動作を確認し、その後パドルと本体ボタンを試してください。

旧版からの更新：変換をCtrl+Cで終了し、最新版の mesen_fire.ps1 と EgretButtons.cs を同じフォルダへ保存してから再起動します。編集済みの buttons.json は残してください。全アプリ対応はアプリ名による制限を外す機能で、MAME側の入力方式やキー割り当ての設定も必要です。

よくある問題

MAMEで回転は動くが、本体ボタンだけ効かない

普通のキーボードのSpaceでは発射でき、変換画面に Key down: 0x20 / Key up: 0x20 も出る場合は、旧版でキーのスキャンコードを0としていた不具合の可能性があります。最新版の EgretButtons.cs へ更新し、変換を終了・再起動してください。修正版では正しいスキャンコードを送り、MAMEUI64 0.263.0で発射を確認しています。

Mesen以外でも使える？

最新版は全アプリで有効です。通常のキーボードと同様に操作中のアプリへキーを送ります。MAMEでは入力方式を win32 に変更し、ゲームごとのキー割り当ても合わせてください。全アプリでの動作を保証するものではありません。

起動時にJoin-Pathの「Pathが空の文字列」エラーが出る

初期配布版の起動処理の不具合です。最新版ZIPの mesen_fire.ps1 に置き換えてください。編集済みの buttons.json はそのまま使えます。修正版はWindows PowerShellとCMDからの起動、日本語・空白を含むフォルダでの起動をテストしています。

アルファベットキーを割り当てたい

A〜Z に対応しています。例："topLeft": "Z"。保存後にボタン変換を再起動し、Mesen側でもZに機能を割り当ててください。

パドルが反応しない

MesenのArkanoid Controller設定、AutoHotkey v2の実行状態、普通のUSBマウスでのVAUS動作を確認してください。

「71 hotkeys have been received...」と出る

イーグレットツーミニは短時間に大量のホイール入力を送ります。配布版の A_MaxHotkeysPerInterval := 500 で警告の閾値を上げています。

「Capture failed: Capturing on 'USBPcap1'」と出る

以前の試作版では、TSharkの正常なステータス出力をPowerShellがエラー扱いしていました。ここにある修正版を使ってください。

TAITO detected が表示されない

USBを抜く → CMDを起動 → Enter → USBを挿す、の順番を確認します。USBPcapのインターフェースが1以外の場合、コマンドプロンプトから START_FIRE.cmd -CaptureInterface USBPcap2 のように正しい番号を指定してください。

Key down: 0x20 と表示されても発射しない

MesenでFireにSpaceキーを割り当てたか、Mesenが前面のウィンドウかを確認してください。

検証したUSB入力

ボタン／状態HID Data（5バイト）
押す前00 00 00 00 00
右ボタン00 01 00 00 00
左ボタン80 00 00 00 00
上部左ボタン02 00 00 00 00
上部右ボタン04 00 00 00 00
上部下ボタン10 00 00 00 00

右は2バイト目の 0x01、左・上部左・上部右・上部下は1バイト目の 0x80 / 0x02 / 0x04 / 0x10 を個別に検知します。Mesenに限らず、操作中のアプリに設定されたキーの押下・解放を送ります。詳しくは 技術メモ をご覧ください。

これは1台の個体とWindows環境での動作報告です。MesenCEのすべてのバージョンや長時間の安定性は未確認です。また、USBPcapは対象機器以外のUSB通信を含む場合があるため、記録ファイルを安易に公開しないでください。
